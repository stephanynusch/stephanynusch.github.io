# Software Engineer Portfolio

An editorial, responsive portfolio built with React, TypeScript, and Vite. It
includes persistent light and dark themes, subtle scroll animation, accessible
navigation, and responsive project layouts.

## Run locally

```bash
npm install
npm run dev
```

## Customize

The resume-based content is centralized near the top of `src/App.tsx`.

- Edit the `experience`, `projects`, and `skills` arrays as your work evolves.
- Replace `public/Stephany_Nusch_Resume.pdf` when your resume changes.
- Update each project link when case studies are available.
- Replace the page title and description in `index.html`.

Visual styles and theme colors are in `src/App.css` and `src/index.css`.
